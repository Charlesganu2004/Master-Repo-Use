# Master Anti-Slop

Remove filler, generic names, invented precision, unsupported claims, duplicate
sections and repetitive template structure. Avoid em dashes. In interfaces,
reject AI-purple defaults, repeated three-card rows, excessive pills and motion
without purpose. In code, reject dead controls, placeholder data, swallowed
errors and tests that only match wording instead of behavior.
