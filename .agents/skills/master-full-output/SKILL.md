# Master Full Output

When implementation is requested, produce the complete working change. Do not
substitute `rest of code`, `same as above`, TODOs, empty handlers or decorative
shells for required behavior. Preserve existing unrelated work. Run the relevant
checks and report actual failures before success. If a hard limit interrupts the
work, stop at a clean boundary and name every remaining item precisely.
