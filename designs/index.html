What every design carries

The differences are visual and navigational. These capabilities stay identical across the collection:

  • Your system first. Windows, Ubuntu/WSL, macOS, Linux or Other. That choice decides the scan command and every command shown afterwards. Nothing is guessed from the browser.
  • Then the numbers. RAM, VRAM, free disk, cores. On macOS the VRAM field disables itself, because unified memory is the same pool as RAM and adding them would overstate what the machine can host.
  • Filters compose across family, kind, sub-category and text. Nothing replaces anything, so lanes intermix.
  • Click anything for a popover with its description, lane and source file, the command for your platform, its connections, and a + button.
  • Build. Plus collects components; the Build tab emits one script that sets all of them up in order, naming anything it skipped and why.
  • Custom lanes and suggestions stay in your browser. These pages transmit nothing.

Open any file directly from disk. No server is needed: the data ships as a script rather than a fetch, because browsers block fetch() over file://.
