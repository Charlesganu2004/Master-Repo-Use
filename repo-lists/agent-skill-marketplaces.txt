                              # LINK ONLY. The name misleads twice over. "local" does not mean
                              # local inference: it means reviewing your working tree instead of a
                              # pull request. And the MIT licence covers install.sh and the plugin
                              # glue, not the product: the actual macroscope binaries are ~33MB
                              # prebuilt Go blobs served from Releases with no source anywhere, and
                              # use "requires an active Macroscope account", so your code goes to a
                              # vendor service. install.sh was read rather than assumed: no sudo,
                              # writes only under $HOME, contacts only api.github.com and release
                              # URLs, no telemetry, no eval or obfuscation, and it does verify
                              # SHA-256 against GitHub's per-asset digests. Three things to know
                              # before running it anyway: the advertised path is curl | bash off
                              # raw main, so it runs whatever main holds at that moment;
                              # REQUIRE_CHECKSUM defaults to 0, so a MISSING digest warns instead
                              # of failing, and fail-closed is opt-in; and three env vars can
                              # redirect where the binary and bundle come from. Listed because it
                              # ships a genuine .claude-plugin/marketplace.json for Claude Code,
                              # Codex, Cursor and OpenCode. Five stars is very little corroboration.
