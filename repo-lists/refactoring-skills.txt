# Refactoring skills and the tools that make one safe - observed 2026-09-09
# Presence here is catalog coverage, not static intake approval or installation.
#
# A refactor changes the inside of code and leaves the outside identical, so the
# whole discipline rests on being able to prove the outside did not move. That
# splits this lane in two: the skill packs that carry the transformation list,
# and the tools that supply the proof. The second half is the half usually
# missing. "Remove Dead Code" written in a skill file is a suggestion; a dead
# code finder that names the symbol and the line is a finding.
#
# The rules live in skills/master-refactor/SKILL.md and
# skills/master-refactor-ui/SKILL.md, not here, for the same reason as the
# computer-control lane: a rule that lives only in a catalog comment is a rule
# nobody reads at the moment it matters.
#

# --- Dead code and duplication finders (the proof a deletion needs before it happens)

jendrikseipp/vulture          # MIT. Python dead code. Reports unused names with
                              # a confidence score, which matters because a
                              # symbol reached by string dispatch is invisible to
                              # it and the score is where that uncertainty shows.

webpro-nl/knip                # ISC. Unused files, exports and dependencies in
                              # JavaScript and TypeScript projects. The closest
                              # thing to a repo-wide proof that an export is
                              # genuinely unreferenced.

kucherenko/jscpd              # MIT. Copy-paste detector across 150+ languages.
                              # Answers "is this duplicated three times or twice",
                              # which is the threshold the skill sets before an
                              # extraction is worth doing.

# --- Mechanical transformation (a rename applied to every call site, not by hand)

facebook/jscodeshift          # MIT. Codemod runner over a JS/TS AST. The point
                              # is that a rename it performs reaches every call
                              # site including the ones grep would miss.

codemod/codemod               # Apache-2.0. Registry and runner for codemods
                              # across languages. Younger than jscodeshift;
                              # listed for the multi-language reach.

asottile/pyupgrade            # MIT. Rewrites Python to newer syntax
                              # automatically. A narrow, behaviour-preserving
                              # transformation applied mechanically, which is
                              # the safest shape a refactor can take.

sourcery-ai/sourcery          # MIT. Suggests refactorings in Python from static
                              # analysis. Read the suggestion before taking it;
                              # a tool that proposes an extraction cannot know
                              # whether the extracted block has a name.

# --- Practice material (a kata where the tests already exist, so the loop is real)

emilybache/GildedRose-Refactoring-Kata  # MIT, 4.2k stars, pushed 18 days before review.

                              # to about 40 languages. Its value here is the
                              # characterisation-test step: the kata cannot be
                              # started until the current behaviour is pinned,
