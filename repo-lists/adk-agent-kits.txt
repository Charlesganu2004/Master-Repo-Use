# Agent Development Kits (ADKs) — first-party, vendor-maintained agent frameworks
# Vetted 2026-08-25. See docs/ADK-GUIDE.md for when to reach for which.
#
# These are the vendor-supported successors to the earlier generation of
# community agent frameworks. microsoft/agent-framework in particular is the
# merged successor to AutoGen + Semantic Kernel.

# --- Google Agent Development Kit (Google's own ADK packages and the samples that ship with them)
google/adk-python
google/adk-java
google/adk-samples
google/adk-web

# --- Microsoft (Microsoft's agent frameworks and the orchestration layer above them)
microsoft/agent-framework
microsoft/semantic-kernel

# --- OpenAI (OpenAI's agent SDKs and the tool-calling surfaces they expose)
openai/openai-agents-python
