# Computer control candidates - observed 2026-09-09
# Presence here is catalog coverage, not static intake approval or installation.
#
# This lane is different from every other lane in the catalog, and the difference
# is worth saying before the first entry: these grant a model the mouse, the
# keyboard, the screen and the clipboard of a real machine. Nothing else in this
# repository does that. A skill writes text. A tool runs a command you can read
# first. One of these can click "Confirm" on a dialog you never saw.
#
# So the rules around this lane are stricter, and they are in
# skills/master-computer-control/SKILL.md rather than here, because a rule that
# lives only in a catalog comment is a rule nobody reads at the moment it
# matters. The short version: nothing here is auto-installed, nothing here runs
# without Charles enabling it per session, and the guards still apply.
#
# The catalog already carried the OBSERVATION half of this problem in
# chat-code-monitor.txt: screenpipe, openrecall and activitywatch watch a screen.
# None of them touch it. That is the line this lane crosses.
#
