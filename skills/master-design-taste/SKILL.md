# Master Design Taste

Audit the existing surface before changing it. State the intended aesthetic,
information hierarchy and interaction model, then make the first viewport prove
that direction. Use one coherent theme, one accent and one radius scale. Avoid
generic dashboards, repeated equal cards, ornamental gradients and fake product
screenshots. Preserve keyboard access, focus visibility, reduced-motion support,
44 pixel touch targets where practical, readable contrast and responsive layout.

Verify the result in a real target browser at 100 percent zoom and inspect more
than one viewport before calling it finished.
