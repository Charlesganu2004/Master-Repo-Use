MCP Tools & APIs

  • Filesystem MCP — scoped to allowed paths only, never root
  • GitHub MCP — limited toolsets (repos, issues, PRs, security)
  • Playwright MCP — browser automation for research and verification
  • Context7 — live library documentation lookup
  • Alpaca MCP — paper trading (never live without explicit approval)
→ MCP Servers guide → Agent access profiles

RAG · Memory · Context

  • LightRAG — graph-based RAG with entity awareness
  • Upstash vector-js — serverless vector store
  • AgentMemory — persistent durable memory across sessions
  • LLMLingua — prompt compression (reduce tokens before sending)
  • Context-Gateway — compression proxy layer
→ RAG & Memory catalog → Token efficiency guide

Cost Controls

  • /compact — compact session before context limit. Relay writes a handoff note first.
  • Token budget — set ANTHROPIC_MAX_TOKENS env var before starting
  • Model routing — Haiku for simple tasks, Sonnet for most, Opus for deep reasoning
  • Tool allowlist — expose only tools the agent actually needs for this task
  • Penny audits bloated sessions and flags top 3 optimizations
→ Full token efficiency guide → Penny (cost auditor)

Output

  • Cloud service — Azure, AWS, GCP via Volt or Nimbus agents
  • Database — via data pipeline (Schema, Vector agents)
  • Broker — paper orders only unless live mode explicitly approved in conversation

Before a Run

  • Run Lens to check what is in context
  • Count tokens before sending a large prompt
  • Set ANTHROPIC_MAX_TOKENS to cap the session
  • Choose the cheapest model that can do the task
→ Token efficiency guide→ Lens agent

Prompt Caching

  • Add cache_control: {type: "ephemeral"} to your system prompt
  • Cache TTL: 5 minutes in the Anthropic API
  • Saves input token cost on every cached call
  • Best for: agent system prompts, tool schemas, stable repo catalogs
→ Caching guide with code

Context Compression

  • LLMLingua — compress long documents by ~50% while preserving meaning
  • Context-Gateway — proxy layer that compresses before sending to LLM
  • RAG retrieval — retrieve top-3 chunks instead of loading whole documents

Tool Schema Slimming

  • Use GITHUB_TOOLSETS to limit which GitHub tools are exposed
  • Remove tool descriptions over 50 words — trim to the core
  • Remove optional parameters the agent never uses
  • Run MCP inspector to see actual schema sizes
→ Agent access profiles

Mid-Run /compact

  • Relay writes a handoff note first (agents/handoff-relay.md)
  • Type /compact in Claude Code
  • Context window resets, handoff note preserved in issues/
  • Session continues from the checkpoint
→ Relay (handoff agent)

Model Routing

  • Haiku 4.5 ($0.80/$4.00 per 1M): scanning, classification, summarization
  • Sonnet 4.6 ($3.00/$15.00 per 1M): code, analysis, most agent tasks
  • Opus 4.8 ($15.00/$75.00 per 1M): security, architecture, deep reasoning
  • Fable 5: long-form writing, narrative, pitch decks

Post-Run Audit

  • Penny reviews the session: system prompt size, tool schemas, model tier used
  • Penny flags if Opus was used where Sonnet would have sufficed
  • Findings go to issues/ for next session
